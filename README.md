# Huemen

Projects, invoices, payments and receipts for freelance work — INR & USD, synced across phone and laptop.

**App:** https://ixdvivek.github.io/huemen/ (add it to your home screen to use it like an app)

- Projects with clients, hourly rates and deliverables
- Invoices: advance, mid-project, additional work, final settlement or custom
- UPI scan-to-pay QR on INR invoices
- Record full or part payments → automatic receipts
- Share invoices and receipts as an image or PDF

Built with React + Vite, data in Supabase, hosted on GitHub Pages. See `CLAUDE.md` for how it's put together.

```bash
npm install
npm run demo   # sample data, no login
npm run build
```
